# Установка и первый запуск

1. Откройте [релизы ChrysNeb/Shakalizator](https://github.com/ChrysNeb/Shakalizator/releases).
2. Скачайте `Shakalizator-1.0.0.apk` на Android 8.0 или новее.
3. Установите APK, разрешив установку из браузера / файлового менеджера, которым открыли файл.
4. Выберите фото, видео, аудио, текст или Шакалографию.
5. Для медиа нажмите выбор файла, для текста вставьте сообщение. Выберите уровень и запустите обработку.
6. Нажмите скачать: Android предложит выбрать имя файла и папку. Пока окно выбора открыто, данные в интернет не отправляются.

## Разрешения

Доступ к интернету отсутствует. Выбор / сохранение файлов — через системные окна, без разрешения на всю память. Микрофон запрашивается отдельно при записи аудио; можно отказать и использовать готовый файл.

## Если что-то не работает

- Обновите **Android System WebView**. Нужен современный движок с WebAssembly, module workers и WebCrypto.
- Держите приложение открытым во время обработки.
- Для видео / аудио начните с 5–15 секунд; очень большие файлы могут не поместиться в память.
- Если приложение сообщает о нехватке памяти, выберите файл поменьше или короткий отрезок.
- Если Android не умеет декодировать фото HEIC, сохраните его в JPEG.
- Для сохранения проверьте свободное место и доступность выбранного хранилища.

Кнопка «Веб-версия ↗» намеренно открывает внешний браузер на [shakalizator.space](https://shakalizator.space). Для загрузки сайта нужен интернет; сами выбранные файлы веб-версия обрабатывает в браузере.

Это предварительная debug-сборка для прямой установки, не магазинный релиз. Пакет `space.shakalizator.app` отличается от пакета «Шакал Камеры»: приложения устанавливаются рядом.
