# Проверка Android-приложения 1.0.0

13 ноября 2026.

## Выполнено

- APK собран локально и в GitHub Actions.
- 3 unit-теста: безопасное имя результата, кириллица / расширения, нормализация MIME.
- `node tools/check-bundle.mjs`: SHA-256 включённых библиотек, локальные пути и отсутствие INTERNET; 6 МиБ + 173 байта прошли через 64-КиБ экспортные чанки без потерь (мок нативного приёмника).
- Android Lint: 0 ошибок, 7 предупреждений.
- 5 инструментальных тестов прошли на **Android 15 / API 35**, x86_64-эмуляторе GitHub:
  1. В APK нет INTERNET; хаб, пять инструментов и описание открываются локально.
  2. Фото: 33 комбинации (1–10 и 12/10 × Paint / Nearest / Чистый) дают не чёрный результат.
  3. Текст: уровни 1–10, повторяемый seed, обратимые двойные кракозябры; копирование через настоящий Android ClipboardManager.
  4. Криптография: защищённый origin, PBKDF2/AES в Web Worker, уровни 1/6/12, восстановление текста с кириллицей и эмодзи, обратимая упаковка в пиксели PNG-пакета.
  5. Локальное WASM-ядро: синтетический звук и видео; аудио уровней 1/7/10/12, видео 1/6/10/12 сформировали результаты MP3/MP4. Снаружи APK никаких ресурсов не запрашивалось.
- Счётчик попыток загрузки внешних ресурсов во всех Android-тестах равен нулю.
- Снят и просмотрен настоящий скриншот Android-хаба, помещён в README.
- Подпись APK проверяется apksigner (v2). Минимум Android 8.0 / API 26, target SDK 35; Java + WASM, без архитектурно-зависимых JNI-библиотек.

## Что остаётся ручной проверкой

- Системные окна выбора / сохранения с разными DocumentsProvider на реальном телефоне.
- Микрофон, его разрешение и запись настоящего голоса.
- Крупные / длинные файлы, нехватка памяти и разнообразие версий System WebView.
- Дополнительный тяжёлый экспорт DSD256 не включён в Android-прогон.
- Независимого аудита криптографии не проводилось. Локальность и отсутствие INTERNET не гарантируют безопасность заражённого устройства.

Это предварительная debug-сборка для прямой установки. Эмуляторные тесты не заменяют проверку на всех телефонах.
